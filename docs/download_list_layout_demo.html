设计要点

  1. 标题吃满整行：14.5px / 600 字重，最多 2 行（超出省略），点标题可展开全文，不再出现「[萧…」。
  2. 字段改为「标签 + 值」成组：下载组（进度·章节·速度）与转换组（进度·章节·耗时）各占一行，标签 10px 灰、值 12px 等宽数字，三列固定比例对齐，行与行之间列位一致。
  3. 状态用徽章代替文字列：完成绿 / 进行中橙 / 等待灰 / 失败红，固定在每行最右侧成一列，既不挤占标题宽度，也不用再单开「下载状态 / 转换状态」两列。
  4. 顶部筛选区压缩：下拉 + 搜索并排、5 个动作按钮压成一行、3 个复选 + 1 个单选合成一行，比现状少约 60px 高度，且「超分跳过损坏」不再被右边缘裁掉。
  5. 排序移出表头：改为右侧「排序：添加时间」小控件，去掉 11 个表头占用的 34px 高度。
  6. 不再横向滚动：所有列在 478px 内排完，极端数据只在单元格内省略（悬停/长按看全文），不会整列跑出屏幕。

两方案取舍

  1. A 卡片式：标题可读性最好，双行标题 + 两行指标，一屏约 8 项。适合「看清单、找某本」。
  2. B 分组三列：标题列 2 行但更窄，下载/转换各一列竖排「进度 / 章节 / 速度(耗时) / 状态」，一屏约 11 项。适合「盯进度、批量操作」。
  3. 两者都能直接落到 QTableWidget（把 2~3 行文本塞进一个单元格 + 固定行高）或换成 QListWidget + 自定义 item widget。
