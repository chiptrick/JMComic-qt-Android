改了什么

  1. 线路选择恢复原设计：表头「Api分流 / 延迟 / 图片分流 / 速度」四列，6 行（分流1~4、US反代分流、IP分流）。每个分流独占一行，名称不再被截，「连接超时」和「4.71MB/s」都能完整显示。
  2. 列表跟随整页滚动：去掉列表自身的滚动条，表格高度 = 行数 × 行高（50 × 62 = 3100px），整页统一滚动。
  3. 高级面板：高度用非线性缓动做展开/收起，同时淡入 1px 橙色描边 + 内高光 + 上投影。
  4. 代理设置 / 节点列表 / 高级面板内容：布局与样式保持上一版不变。

要注意的代价

  1. 整页从 1 屏变成约 4 屏：50 个节点全在页面里，滚到底才能按到「测试 IP 分流」（或在底部固定栏）。
  2. Qt 落地必须先解决手势归属：表格不再滚动后，如果 QScroller 仍装在表格视口上，手指按在列表上拖会「什么都不滚」。要么让 MakeScrollable 跳过无滚动量的视图，要么把列表换成普通 QWidget 卡片流。
  3. 50 张卡片常驻（不再有 viewport 复用），滚动时整页重绘范围更大，真机需要实测帧率。
  4. 收起时面板高度为 0，边框要跟着一起淡出，否则会留一条 2px 亮线。
