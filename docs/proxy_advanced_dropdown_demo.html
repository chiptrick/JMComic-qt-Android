为什么现在点不开 / 点不中

  • 地区候选从来没被填过。全仓库只有 dohLine.SetWordData()，proxyIpEdit 一次都没设过候选 —— 弹出来也是空盒子。
  • 已聚焦时再点不弹。ShowListView() 只挂在 focusInEvent 上，而 _FocusInput() 在已聚焦时直接 return False，不再触发聚焦事件。
  • 按在弹层上第一下就被判成“点外面”。_OutsideHider 用 widget.isAncestorOf(obj) 判断，而手机上 obj 是宿主窗口 → 落下瞬间弹层就收起，clicked 永远不发。
  • 超时下拉是原生 QComboBox（WheelComboBox），弹层是独立 popup 窗口 —— 与“第二个顶层窗口在 Android 上点不动”同源。

确认后的落地改动

  • login_proxy_new_widget.py：GetProxyIpBack() 后按 item.country 去重 → SetWordData()；选中时写 Setting.ProxyIpCountry 并重发请求。
  • tip_line_edit.py：新增 Popover()，点击/聚焦都走它（已聚焦也能唤出）；DOH 弹层底部加「添加」行。
  • popup_list.py：_OutsideHider 改用触点坐标与弹层矩形比较；加 QPropertyAnimation + OutBack 240ms；wheel_combo_box.py 复用同一套。
