waifu2x 模型列表 排版重构草案

旧表是 4 列定宽 200+150+100+100=550，加弹窗内边距后约 578，480 逻辑宽的手机上必须左右滑；现有手机补丁是把「耗时」列 setColumnHidden 掉。本方案换成「3 列网格 + 算法分组行卡」，四个字段一个不藏、不横向滚动。

上一版草案 · 实现已按确认结论调整

实际落地与这里的差异：① 不再展示完整 ID（改成「模型族 / 倍数·降噪」两行）；② 分组条改成吸顶固定；③ 增加「当前使用」角标。本页保留用来对照方案演变。

关键改动

  • 放弃 4 列表格：QTableWidget 的列宽合计永远和屏宽打架，改成 QListWidget + 自绘 delegate，三列由同一套 grid-template 决定。
  • 分组取代「算法」列：41 项按 Waifu2x / Real-CUGAN / Real-ESRGAN 分段，算法名只画一次，省下的宽度全给模型名。
  • 耗时做成数字列：等宽 + 右对齐 + 固定 50px，扫一眼就能比较 100%↔600%。
  • 入口统一：阅读页、超分页、批量页的「模型」按钮全部换成整行「选择栏」（短名 + 倍数/降噪 + 完整 ID），不再把 33 字符塞进 90px 按钮。
  • 阅读页菜单（截图那页）：原来 35px 标签 + 剩余宽度按钮，默认 setEnabled(False) 只显示灰字 AnimaVideoV3，倍数要靠上一行单独看。改成整行选择栏 + 明确「锁定/可更换」两态，锁定时字段仍然完整可读。

待你确认

  • 「同一屏」的口径：我按「单条信息的所有字段都在屏宽内、不用左右滑」理解。若你要的是 41 项一屏不滚动，得走双列小卡（字号 10px），可再加一版。
  • 完整 ID 要不要露出来：现在看图页只显示 Waifu2x(cunet)，9 个 CUNET 变体全同名，用户分不清 2X/D3。我建议主行直接露 ID。
  • 分组 vs 平铺：分组省宽度但少了「按耗时排序」的全局视图；demo 里点表头「耗时」会自动切成平铺排序，你试试哪种顺手。
  • 是否加「当前使用」高亮：弹窗现在没有回显（curModelName 传进来根本没用），demo 里已经做了回显 + 自动滚到当前项，要不要顺手补上。
  • 分组条要不要吸顶：demo 里是不吸顶的（滚动时整条跟着走）。吸顶能一直看到算法名，但滚动态会在分组条下方露出一截行，静态截图里很像重叠，所以我先关掉。
  • 阅读页的两段式要不要保留：现在是点「修改参数」才解锁模型、出现「保存」。这样能防误触，但很多人根本找不到入口。也可以改成常亮可点、选完即生效（少一次点击）。
