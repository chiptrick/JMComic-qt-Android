# 格式: <模型名> <onnx文件名> <原生放大倍数> <降噪等级> <固定输入边长>
#   - 模型名与桌面端 sr_vulkan 的 MODEL_* 常量一致(去掉 MODEL_ 前缀)
#   - 固定输入边长: QNN EP 不支持动态 shape，ONNX 必须导出成固定 N x 3 x T x T
#                   (见 tools/prepare_models.py，默认 T=192)
#   - 可以用 "#" 注释；不写在这里的模型使用内置默认表(指向同名 onnx)
#   - 文件缺失时引擎会自动选择最接近的可用模型，超分功能不会失效

#   * CUNET 权重里的分组反卷积在 HTP 上编译/精度都不友好，NPU 后端默认复用
#     ANIME(动漫) 模型。如需真 cunet，把导出的 cunet onnx 放到 models/ 并把
#     下面的文件名改掉即可。
#   * 想要更高速度可用 prepare_models.py --quantize 生成 uint16/uint8 量化模型
#     (QNN HTP 只原生支持量化模型；fp32 模型靠 enable_htp_fp16_precision 走 fp16)。
